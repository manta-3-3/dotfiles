# My dotfiles managed by chezmoi

## How to use (first use)
1. install chezmoi on your local system
2. run command `chezmoi init https://github.com/manta-3-3/dotfiles.git`, to checkout this repo
3. run command `chezmoi diff`, to see what would be changed
4. run command `chezmoi apply`, if you are happy with the changes
5. and last but not least, have fun and be super-productive with my custom dotfiles made with love :)

## How to update
1. run command `chezmoi update --apply=false`, to pull changes from the source repo
2. run command `chezmoi diff`, to see what would be changed
3. run command `chezmoi apply`, if you are happy with the changes
